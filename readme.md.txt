# 📈 Streamlit Stock Portfolio App

A stock portfolio web app built with Streamlit.

## Features
- Search any stock
- View daily price changes
- Track a portfolio
- Get stock suggestions
- Interactive charts

## Tech Stack
- Python
- Streamlit
- yFinance
- Pandas

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_portfolio_app.py
